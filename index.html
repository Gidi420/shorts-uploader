Shorts Uploader

Shorts Uploader (Google Cloud app name "Shorts uploader") is a small private program used only by the owner of two YouTube channels, Historys and storydark.

It runs on the owner's own computer and uploads the channels' own Shorts through the YouTube Data API, setting each video's title, description and scheduled publish time. It is not offered to the public and has no other users.
