Privacy policy

Shorts Uploader. Last updated 25 November 2026.

Shorts Uploader is a private tool used only by the owner of the Historys and storydark YouTube channels to upload those channels' own videos.

What it accesses

With the owner's permission, it uses Google's YouTube Data API to upload videos to the owner's channels and to read basic information about those channels: the channel name, channel ID and the titles of recent uploads (to avoid uploading the same video twice).

What it stores

The sign-in token is stored only on the owner's own computer. A local log records which videos were uploaded and when. Nothing is stored on any server.

Sharing

No data is sold, shared with third parties or used for advertising. The tool does not access, collect or store any data about other YouTube users.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

Shorts Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
